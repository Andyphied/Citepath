# RAG-006 Implementation Note

## Summary

Added paginated conversation list and detail APIs so engineers can review saved RAG Q&A history with citations. Conversation access is creator-only within the workspace, matching existing `conversation_id` ownership checks on query.

## Files Changed

- `app/api/routes/conversations.py`
- `app/api/deps.py`
- `app/main.py`
- `app/modules/rag/conversation_service.py`
- `app/modules/rag/repository.py`
- `app/modules/rag/schemas.py`
- `app/modules/rag/prompt_builder.py` (`MAX_HISTORY_TURNS` aligned to 5)

## Behavior Added

- `GET /workspaces/{workspace_id}/conversations` — paginated list (`page`, `page_size`) of the caller's conversations in the workspace.
- `GET /workspaces/{workspace_id}/conversations/{conversation_id}` — conversation summary plus ordered messages; assistant messages expose parsed `citations` from stored metadata.
- Both endpoints require workspace membership and `QUERY_RAG` permission.
- Foreign or other-user conversations return `404 not_found` (no enumeration).
- LLM prompt history window limited to the last 5 turns (10 messages).

## Tests Added

- `tests/api/test_conversations.py`
- `tests/unit/test_rag_conversation_service.py`
- `tests/unit/test_rag_prompt_builder.py` (history window = 5 turns)

## Decisions Made

- Reused `ConversationNotFoundError` and existing RAG error handler for missing/non-owned conversations.
- Parsed citations into a top-level `citations` field on message responses while preserving full `metadata` for audit/debug fields.
- List endpoint scopes to `user_id` so workspace members only see their own conversations (MVP creator-only detail policy).

## Known Limitations

- Admin/owner cross-user conversation visibility deferred (MVP creator-only).
- No delete/archive conversation API in this story.
