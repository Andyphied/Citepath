# ING-007 Implementation Note

## Summary

Added transient vs permanent failure classification for ingestion jobs, Celery task-level retries with exponential backoff (max 3), and `attempt_count` tracking across retries. Permanent failures (empty/no extractable text, corrupt/unsupported content) fail immediately without autoretry. Manual retry remains DOC-006 re-index (new job).

## Behavior Added

- Worker classifies embedding/storage failures as retryable (timeouts, connection/rate-limit errors) or permanent.
- Retryable failures leave job/document in `processing`, schedule Celery retry with `countdown = min(2^retries, 60)`, max 3 retries.
- On retry exhaustion, job → `failed` with last error message; document → `failed`.
- Permanent failures (including `no extractable text`) call `_fail_ingestion` immediately; Celery `retry` is not invoked.
- `attempt_count` increments on each worker start (including redeliveries).
- Manual path: `POST .../documents/{id}/reindex` (DOC-006) creates a new ingestion job — no dedicated `/retry` endpoint.

## Decisions Made

- Extended existing `attempt_count` and ING-004 batch micro-retry; did not rewrite the ingestion stack.
- Explicit `task.retry()` with `MaxRetriesExceededError` handling instead of only `autoretry_for`, so the job is marked `failed` when retries are exhausted (avoids stuck `processing`).
- No thin retry API — DOC-006 re-index already covers admin manual recovery.
- Empty text reason aligned to story AC phrase `no extractable text`.

## Known Limitations

- Celery countdown is not exercised under `task_always_eager` wall-clock delays in unit tests (retry scheduling is asserted via mocks).
- Unexpected uncaught exceptions still propagate without classification (existing behavior); OBS-005 may tighten logging/metrics.
- Concurrent auto-retry and manual re-index can create multiple jobs for one document (re-index guard only blocks pending/processing latest job).

## Follow-up Items

- Optional dedicated `POST .../ingestion-jobs/{id}/retry` if product wants retry without chunk delete semantics of re-index.
