# DOC-003 Implementation Note

## Summary

Added paginated `GET /workspaces/{workspace_id}/documents` with optional status filter, `VIEW_DOCUMENTS` RBAC for all workspace roles including Viewer, and repository pagination backed by existing `(workspace_id, created_at)` index.

## Files Changed

| File | Purpose |
|------|---------|
| `app/modules/documents/repository.py` | `list_for_workspace_paginated()` with count + offset/limit |
| `app/modules/documents/schemas.py` | `DocumentListResponse` with items, total, page, page_size |
| `app/modules/documents/service.py` | `list_documents()` service method |
| `app/api/deps.py` | `RequireViewDocumentsDep` permission dependency |
| `app/api/routes/documents.py` | List documents route |
| `tests/unit/test_document_repository.py` | Repository pagination unit tests |
| `tests/unit/test_document_service.py` | Service list unit test |
| `tests/api/test_documents_list.py` | API integration tests |

## Behavior Added

- `GET /workspaces/{workspace_id}/documents?page=1&page_size=20&status=indexed`
- Response fields per document: `id`, `title`, `file_type`, `status`, `uploaded_by`, `created_at`, `updated_at` (plus `workspace_id`, `source_type` from existing schema)
- Ordered by `created_at` descending (newest first)
- Viewer, Member, Admin, Owner can list; non-members receive 403

## Tests Added

**Unit:**

- `tests/unit/test_document_repository.py` — pagination offset/limit and status filter
- `tests/unit/test_document_service.py` — paginated response mapping

**API (Docker):**

- `tests/api/test_documents_list.py` — list 5 docs, pagination page 2, viewer access, non-member 403

## Decisions Made

- Pagination uses `page` / `page_size` per `docs/06-api-design.md` (max `page_size=100`)
- Reused `DocumentResponse` for list items rather than a separate list item schema
- Kept legacy `list_for_workspace()` for existing security tests

## Known Limitations

- No `source_type` query filter yet (API design mentions it; deferred)
- Upload-triggered ingestion in API tests means document status may be `uploaded`/`processing` rather than `indexed` during list assertions
