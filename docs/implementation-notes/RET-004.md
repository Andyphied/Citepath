# RET-004 Implementation Note

## Summary

Added optional metadata filters (`file_type`, `source_type`, `document_id`) to the retrieval pipeline. Filters are applied in SQL alongside `workspace_id` via a join to `documents` when document metadata filters are present. RAG query API accepts nested `filters` on `POST /workspaces/{workspace_id}/query`.

## Behavior Added

- `RetrievalService.search(filters=RetrievalFilters(...))` applies optional filters before scoring.
- Invalid `file_type` values return validation error (`InvalidRetrievalFilterError` at service layer; 422 via Pydantic on API).
- Migration adds `(workspace_id, file_type)` and `(workspace_id, source_type)` indexes.

## Tests Added

- Integration: MD + PDF chunks; `file_type=pdf` returns PDF chunk only
