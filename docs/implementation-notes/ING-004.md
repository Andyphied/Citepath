# ING-004 Implementation Note

## Summary

Implemented batch embedding generation for ingestion `ContentChunk` outputs using an `EmbeddingProvider` abstraction (`OpenAIEmbeddingProvider` via ADR-003). The worker embeds chunks after chunking, retries each failed batch once, logs `ingestion_embedding_completed`, and records per-batch usage events for the ingestion path (USAGE-002 scope in this delivery). Embedded vectors are held in-memory as `EmbeddedChunk`; pgvector persistence is deferred to ING-005.

## Behavior Added

- `EmbeddingProvider.embed(texts)` returns normalized `EmbeddingResult` with vectors, token count, model, and latency.
- `create_embedding_provider(settings)` builds `OpenAIEmbeddingProvider` for MVP.
- `embed_content_chunks(...)` batches by `EMBEDDING_BATCH_SIZE`, retries each batch once on provider failure, and returns `list[EmbeddedChunk]` or `EmbeddingError`.
- Each batch logs one `usage_events` row via `UsageService.log_event()` with `operation=embedding`, `user_id=null`, and metadata `{document_id, job_id, batch_size}`.
- Failed batches after retry log a `status=failed` usage event before failing the job.
- Usage logging failures are caught and logged; they do not fail ingestion.
- Worker logs `ingestion_embedding_completed` with `chunk_count` on success.
- Embedding failures call `_fail_ingestion` with a truncated error message.

## Decisions Made

- Introduced `EmbeddedChunk` alongside `ContentChunk` rather than mutating chunker output in place.
- Usage logging lives in `modules/ingestion/embeddings.py` for worker batch orchestration; provider layer stays vendor-only per ADR-003.
- Used ADR-007 `operation=embedding` (not story draft `embedding_document` / `embedding_query`) for consistency with schema enum.
- USAGE-002 **ingestion path only** delivered here; query-side embedding usage remains pending for RET-001 / separate gate. Story `usage-002-log-embedding-calls.md` stays `pending`.
- Vectors are not persisted in this story; `_ = embedded_chunks` placeholder until ING-005.

## Known Limitations

- Only OpenAI embedding provider implemented; Anthropic chat does not affect embeddings in MVP.
- No pgvector write or job completion — ING-005 follow-up.
- Cost table is static and approximate (USAGE-003 may extend).
- `MockEmbeddingProvider` used in tests; no live OpenAI integration test.
