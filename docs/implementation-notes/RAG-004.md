# RAG-004 Implementation Note

## Summary

Added citation mapping from retrieved chunks and LLM cited IDs to API `citations[]`, with document title, chunk preview, score, and optional page/section metadata. Citations are persisted on assistant `Message.metadata_`.

## Files Changed

- `app/modules/rag/citation_mapper.py`
- `app/modules/rag/schemas.py`
- `app/modules/rag/query_service.py`

## Behavior Added

- Response includes `citations[]` with `chunk_id`, `document_id`, `document_title`, `chunk_preview`, `score`, and metadata.
- Invalid LLM chunk references are stripped with server-side warnings.
- Assistant messages store serialized citations under `metadata.citations`.
- Inline `[1]` markers supported when returned by the model.

## Tests Added

- `tests/unit/test_rag_citation_mapper.py`
- `tests/integration/test_rag_query_service.py`
- `tests/api/test_rag_query.py`

## Decisions Made

- When the model omits `cited_chunk_ids`, all context chunks are cited (non-empty when context used).
- Preview length reuses retrieval `CONTENT_PREVIEW_MAX_LENGTH` (200 chars).

## Known Limitations

- RET-005 dedicated chunk preview endpoint not implemented; preview comes from retrieval/search path.

## Follow-up Items

- Stricter claim-to-citation validation if product requires post-processing beyond MVP.

## Co-shipped Coverage

- **RAG-005:** insufficient-context responses return empty citations.
- **USAGE-001:** unchanged; citations do not affect usage logging.
