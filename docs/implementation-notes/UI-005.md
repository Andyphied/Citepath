## Behavior Added

- `/agent` posts trimmed `objective` to `POST /workspaces/{id}/agent-runs` (sync; no polling)
- Running state disables Start and shows “Running investigation… this can take up to ~120 seconds.”
- Client aborts after `AGENT_RUN_TIMEOUT_MS` (120s) and surfaces `agent_timeout` with Retry
- Completed runs render story sections mapped to API fields:
  - Summary ← `problem_statement` + `summary`
  - Likely related systems ← `likely_related_systems`
  - Relevant documents ← `related_documents` (titles from citations when available)
  - Suggested checks ← `recommended_checks`
  - Risks / unknowns ← `risks_or_unknowns`
  - Next steps ← `next_steps`
  - Sources ← top-level `citations` (reuses Ask `CitationList`)
- Each card shows the API field name under the story heading
- Workspace change clears result/error and discards mid-flight responses via `requestWorkspaceId` + `activeWorkspaceIdRef`

## Decisions Made

- Sync wait only (story allows sync MVP); no streaming/polling UI
- Timeout enforced client-side with `AbortSignal` so hung runs unlock the form
- Card headings use story labels; mono subtitle shows the exact `InvestigationSummary` / `citations` field name
- `likely_causes` and `action_items` exist on the API but are not rendered (not in UI-005 / AGENT-008 demo section list)
- Sources reuse Ask citation expanders rather than inventing a second citation component

## Known Limitations

- Non-streaming only (submit locked for the full round-trip / timeout)
- No tool-call timeline UI (AGENT-009 list endpoint unused)
- Related documents without matching citations show a shortened UUID, not a deep link
- No browser E2E covering indexed demo docs → populated sections
- Workspace switch mid-flight still shows the global running spinner until the orphaned request settles (`setRunning(false)` in `finally`)
