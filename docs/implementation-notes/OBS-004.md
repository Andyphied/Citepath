# OBS-004 Implementation Note

## Summary

Introduced a shared standard API error envelope under `app/modules/observability/errors.py` with shape `{ "error": { "code", "message", "details", "request_id" } }`. Registered global FastAPI handlers for `RequestValidationError` (422 with field details) and unhandled `Exception` (500 with generic client message and server-side stack logging). Refactored auth and workspace domain exception handlers to use the shared builder so all error responses include `request_id`.

## Behavior Added

- **422 validation errors** — FastAPI `RequestValidationError` mapped to `validation_error` with field-level `details` (e.g. `"password": "String should have at least 8 characters"`).
- **500 unhandled exceptions** — Generic `internal_error` message returned to clients; full stack trace logged via structlog at error level with `request_id`, path, and method.
- **request_id in all error bodies** — Domain handlers (auth, workspace) and global handlers include `request_id` from `get_request_id_from_request()`.
- **Consistent envelope** — All structured errors use the same top-level `error` object.

## Tests Added

**Unit (`tests/unit/test_api_errors.py`):**

- `build_error_body` includes request_id
- `validation_details_from_errors` maps Pydantic loc/msg to field details
- Validation handler returns 422 envelope
- Unhandled handler returns 500 without leaking exception text

**API (`tests/api/test_api_error_format.py`):**

- `POST /auth/register` with short password → 422 structured validation error
- `GET /auth/me` unauthenticated → 401 with `request_id` in body matching header
- Test route raising unhandled exception → 500 generic envelope, no stack in body

**Updated:** `test_auth_register.py`, `test_auth_login.py` — 422 tests assert standard envelope instead of FastAPI `detail`.

## Decisions Made

- **Module location** — Error helpers live in `app/modules/observability/` per modular monolith boundaries; domain handlers in `app/api/` delegate to shared builder.
- **Validation details shape** — Flat `field -> reason` map derived from Pydantic error `loc` (skipping `body`/`query`/`path` prefixes); multiple errors on one field are concatenated.
- **Generic Exception handler** — Registered last; domain-specific handlers remain more specific in FastAPI MRO lookup.
- **HTTPException deferred** — No app usage today; AUTH-006 can add handler if needed.
- **500 message** — Fixed generic string; no exception type or message exposed to clients.

## Known Limitations

- `HTTPException` and other Starlette/FastAPI built-in errors not yet normalized (AUTH-006 scope).
- Validation `details` uses simplified field keys; nested model paths joined with `.` but not full JSON pointer paths.
- `request_id` may be `null` if error occurs before middleware sets context (unlikely for normal HTTP flow).
