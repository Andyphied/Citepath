# DOC-004 Implementation Note

## Summary

Added `GET /workspaces/{workspace_id}/documents/{document_id}` returning document metadata, latest ingestion job, chunk count for indexed documents, and error message for failed documents. Workspace-scoped lookups return 404 when the document is missing or belongs to another workspace.

## Behavior Added

- `GET /workspaces/{workspace_id}/documents/{document_id}` with `VIEW_DOCUMENTS` RBAC
- Response includes `document`, `latest_job`, `chunk_count` (indexed only), `error_message` (failed only)
- Does not expose `storage_key` or raw storage paths
- 404 for missing or cross-workspace document access

## Decisions Made

- `error_message` surfaced at detail level from latest ingestion job when document status is `failed`
- `chunk_count` computed via SQL `COUNT` only when status is `indexed`
- ING-007 not required — read path uses existing job error persistence from worker

## Known Limitations

- No chunk preview or job history list (latest job only)
- Processing/uploaded documents return `chunk_count=None` until indexed
