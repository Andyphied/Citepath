## Behavior Added

- `/admin` loads in parallel:
  - `GET .../admin/documents-overview` (status counts + recent uploads)
  - `GET .../admin/usage` (default 7-day window; totals + estimated cost)
  - `GET .../admin/failed-jobs` (24h/7d counts; empty message when none)
  - `GET .../admin/ingestion-jobs` (page 1, size 20; includes `pending_count`)
- Summary cards show corpus health, token/cost totals, and failed-job count (highlighted when `failed_last_7d > 0`)
- Failed jobs card lists ADMIN-005 `items` with document title + `error_message` when failures exist
- Ingestion jobs table shows document title, status badge, started/completed, and error message for failed jobs
- Recent uploads list uses overview `recent_uploads` with document status badges
- Sidebar Admin nav remains `adminOnly` (disabled for Viewer/Member); direct `/admin` visit shows access-denied alert
- Empty states for zero jobs and zero recent uploads
- Workspace switch clears dashboard state; generation token + `shouldApplyAdminResponse` + `dataWorkspaceId` prevent stale apply/loading and cross-workspace flashes

## Decisions Made

- No charts (story: simple cards + tables)
- ADMIN-004 uses existing USAGE-004 `/admin/usage` (no second usage endpoint)
- Member denied same as Viewer (matches `VIEW_ADMIN_DASHBOARD` / WS-005)
- Failed-jobs card uses widget counts plus compact `items` error list; full job history remains the ingestion-jobs table
- Cost formatting shows 6 decimals under $0.01 so tiny demo costs remain visible
- Did not wire ADMIN-003 recent-questions (out of story FR list for UI-006)

## Known Limitations

- No pagination UI for ingestion jobs beyond first page (API supports page/page_size)
- No retry action for failed jobs (ING-007)
- No audit-log panel (AUDIT-007 UI not in scope)
- No browser E2E covering seeded Northstar corpus → non-zero cards
- Failed-jobs card lists ADMIN-005 `items` (compact); full history remains in the ingestion jobs table (first page)
